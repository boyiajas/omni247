# Screenshot Plan

Google Play requires a minimum of 2 phone screenshots. For a stronger first release, prepare 5 to 8.

## Use these screens

1. Map home screen with incident markers visible
2. Report creation flow with category selection
3. Media upload screen showing photo or video attachment
4. Alerts or notifications screen
5. Profile or privacy settings screen

## Capture rules

- Capture portrait phone screenshots only for the first set.
- Use raw screenshots from the device or emulator.
- Do not include the desktop, emulator bezel, VS Code, or notification shade.
- Avoid placeholder data if possible.
- Keep text readable and use real-looking map/report examples.

## Recommended sequence

1. Open the app on the emulator.
2. Navigate to each screen.
3. Use Android screenshot capture inside the emulator or `adb exec-out screencap -p`.
4. Save files as PNG.
5. Upload the strongest 2 to 8 images to the Phone screenshots section in Play Console.

## First two screenshots to prioritize

1. Main map with report markers and the `Report Incident` button
2. Report submission screen with media or location context
